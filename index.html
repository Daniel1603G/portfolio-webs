Webs para locales

Dos modelos de sitio para comercios que hoy solo tienen Instagram. Cada uno se adapta a un local editando un archivo de datos, sin tocar el código.

Estudio de tatuajes

Negro Hueso

Galería filtrable por estilo, equipo, pasos para reservar y pantalla de carga. Las imágenes son patrones generados por código.

Restaurante

La Esquina

Carta de bistró con precios unidos por puntos guía, filtros por categoría y dieta, y platos agotados marcados. La carta sale de un JSON aparte.

Ver la demo →

Los dos locales son ficticios. Nombres, direcciones, teléfonos y fotos son de ejemplo. Las imágenes no son fotos: son patrones geométricos dibujados por código (generar-fotos.js).

Sin frameworks ni build: HTML, CSS y JavaScript. Para adaptar un modelo a un local se edita datos.js; en el de restaurantes, la carta vive aparte en carta.json para poder enchufarla después a un sistema de gestión.

El código está en GitHub.
